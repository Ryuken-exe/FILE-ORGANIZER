# 📁 File Organizer

A simple Python automation tool that organizes files into folders based on their file extensions.

## ✨ Features

* Automatically categorizes files
* Creates folders automatically
* Handles duplicate filenames
* Supports images, videos, PDFs, music, documents, Excel & code files
* Handles file and permission errors

## 🛠️ Built With

* Python
* `pathlib`
* `shutil`

## ▶️ Run

```bash
python file_organizer.py
```

Enter the folder path when prompted, and the program will organize the files automatically.

## 📂 Example

**Before:**

```text
Downloads/
├── photo.jpg
├── resume.pdf
├── song.mp3
└── project.py
```

**After:**

```text
Downloads/
├── Images/photo.jpg
├── PDFs/resume.pdf
├── Music/song.mp3
└── Python Files/project.py
```
